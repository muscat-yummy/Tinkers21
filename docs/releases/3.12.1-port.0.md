# Tinkers21 3.12.1-port.0 — NeoForge 1.21.1 preview

First experimental public preview of the independent Tinkers21 fork. This is not an official SlimeKnights release or an upstream endorsement. Original code/assets and copyright notices are retained under MIT. Upstream's [stated port policy](https://slimeknights.github.io/faq/#can-i-port-to-another-minecraft-version) does not approve independent future-version Forge/NeoForge ports; reviewing that policy does not establish maintainer permission. This fork uses its own public project/display name and directs support to [this repository](https://github.com/muscat-yummy/Tinkers21/issues).

## Install / 導入

- Minecraft 1.21.1, NeoForge 21.1.251 or a later 21.1 build, Java 21.
- Install **both** `Tinkers21-1.21.1-neoforge-3.12.1-port.0.jar` and `Mantle21-1.21.1-neoforge-1.11-port.0.jar` on the client and server. The combined ZIP contains the same two jars and installation/license documents; extract it before placing the jars in `mods/`.
- Do not combine these with other jars providing `tconstruct` or `mantle`. Existing Forge 1.20.1 addons, including TiCEX, require a native source port.
- 両方のJARをクライアント・サーバーの `mods/` に導入してください。ZIP自体を `mods/` に入れないでください。旧ワールドの一般的な移行は未検証のため、別ワールドまたはバックアップしたコピーで試してください。

## Implemented and verified

Native material/tool/modifier components and persistence; Part Builder/Station construction, repair and persisted haste; composited tool and three-family/four-slot armor rendering; Melter, Smeltery, Foundry, casting, fluids, alloying and save/reload; island templates/native generation/persistence, biome spawning, actual slime variants and rendering, ender teleport permission, overslime and spilling; complete native datagen/common tags. An independent addon fixture verifies own-bus registration, modifier hooks/dynamic data, material reload, state/component copies, native capabilities, bidirectional payloads, inventory synchronization and material geometry. Duplicate static registration no longer overwrites the first supplier while throwing.

The two accepted revisions differ only in the client test terminal guard. This release retains their runtime sources/resources and tested dependency/toolchain versions; distribution changes add license notices to both jars, an independent launcher display name and correct expansion of Mantle’s pinned NeoForge dependency metadata. The packaging workflow checks those source boundaries and CI provenance, builds both production assemblies, inspects jar metadata/classes/licenses, excludes verification fixtures records SHA-256 checksums and loads the exact distribution jars in a normally installed NeoForge server through world startup, data reload and clean shutdown. Passed runtime gates are not repeated for packaging/docs-only changes.

## Remaining limits

This is a preview, not a blanket compatibility guarantee for every addon, world or modifier combination. Full TiCEX, Diet and optional external integration stacks, arbitrary old-world/addon data migration, the original Forge JUnit suite and exhaustive world seeds/modifier combinations remain unverified. Phase 8 is the defined API audit and independent addon boundary, not a completed TiCEX port. See [PORTING.md](../../PORTING.md) and [addon migration](../ADDON_PORTING.md) for exact scope and concrete API differences.

Report issues in this repository with loader/mod versions, logs, world steps and other installed mods. Do not send fork-specific support requests to SlimeKnights.
