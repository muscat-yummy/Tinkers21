# Tinkers21 3.12.1-port.3 — duplicate container rendering fix

Minecraft 1.21.1 / NeoForge 21.1.251 / Java 21. Unofficial experimental fork.

The port.2 helper checks did not cover the reported full Foundry screen defect. Mantle's legacy screen code explicitly rendered the background before the native container render did so again. In a multi-panel Foundry screen, the first draw used the input-panel origin, duplicating lava and painting molten iron across input slots. Remove the redundant call from both multi-module and generic container screens.

Full production Foundry GUI verification recreates the old double-background call and its incorrect pixels, then requires one background draw, removal of input-panel iron and shifted lava, and one draw in the generic container. Existing fluid, crystal and core/addon graphical checks also remain required. CI assembles/inspects both actual jars and loads them in a normal installed server before publishing.

Replace BOTH old jars with `Tinkers21-1.21.1-neoforge-3.12.1-port.3.jar` and `Mantle21-1.21.1-neoforge-1.11-port.1.jar`. The fix is in Mantle; keeping Mantle port.0 retains the defect. Keep one jar per mod, on both client and server; do not combine with official Mantle. Back up worlds before updating.

This is a vibe-coded unofficial fork. Switch to the official 1.21.1 release when available for safety and maintenance. Full TiCEX/optional integration stacks and general old-world migration remain unverified. Distribution includes licenses, exact source/CI provenance and SHA-256 checksums.
