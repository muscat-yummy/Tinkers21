# Tinkers21 3.12.1-port.1 — modifier crystal rendering fix

Experimental independent fork for Minecraft 1.21.1 / NeoForge 21.1.251 / Java 21. Not an official SlimeKnights release or endorsement. MIT code/assets and original notices retained.

Fixes invisible modifier crystals, including Ambidextrous (両手利き). Their PNG/model existed, but the resource RGB color was passed to the native ARGB item renderer with zero alpha. The registered item tint now supplies opaque alpha while preserving the exact resource color; blank crystals retain white tint.

The release CI runs the existing strict graphical core/addon checks plus actual crystal tint, atlas sprite, geometry and native item rendering after world reload. Both production jars are assembled/inspected, verification fixtures excluded, and the exact jars load/start/save/stop in an ordinary NeoForge server without runtime ERROR. Unchanged server/data sources retain the previously accepted 25 GameTests and native datagen evidence. SHA256SUMS.txt and provenance.json identify the distribution and its CI source.

Install both Tinkers21-1.21.1-neoforge-3.12.1-port.1.jar and Mantle21-1.21.1-neoforge-1.11-port.0.jar in client/server mods. Replace the previous Tinkers21 jar; do not install both versions. Mantle remains unchanged. Extract the combined ZIP first.
