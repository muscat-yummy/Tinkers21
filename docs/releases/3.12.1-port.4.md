# Tinkers21 3.12.1-port.4 — basin casting and sharp books fix

Minecraft 1.21.1 / NeoForge 21.1.251 / Java 21. Unofficial experimental fork.

Fix fluid-only casting recipe lookup: native Minecraft treated a basin with no item cast as an empty recipe input, even with molten metal present. Include fluid in that emptiness check so actual faucets can pour iron/gold into seared basins and scorched basins with a gold platform. Scorched basins still require a cast or gold platform by design; the Japanese tooltip now states this requirement. One metal block uses 810 mB (nine ingots).

Fix blurry Materials and You / Puny Smelting covers and pages: apply the native background blur before drawing the book, then draw navigation widgets once above it. The real graphical regression reproduces the old late blur and compares actual framebuffer sharpness for both books' covers and pages. Existing crystal, tank, full Foundry, equipment, slime and independent addon checks remain required.

CI runs all 26 actual Minecraft GameTests, including four real faucet/basin iron/gold lanes, and the strict graphical client, assembles/inspects both production jars and loads the packaged jars in a normal installed server before publishing. Pinned runner, Java, Gradle, dependencies and native runtime commands are preserved.

Replace BOTH old jars with `Tinkers21-1.21.1-neoforge-3.12.1-port.4.jar` and `Mantle21-1.21.1-neoforge-1.11-port.2.jar`. Keeping older Mantle leaves book blur unfixed. Keep one jar per mod on both client and server; do not combine with official Mantle. Back up worlds before updating.

This is a vibe-coded unofficial fork. Switch to the official 1.21.1 release when available for safety and maintenance. Full TiCEX/optional integration stacks and general old-world migration remain unverified. Distribution includes licenses, source/CI provenance and SHA-256 checksums.
