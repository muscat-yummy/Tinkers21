# Tinkers21 3.12.1-port.2 — fluid GUI rendering fix

Unofficial, experimental Minecraft 1.21.1 / NeoForge 21.1.251 port. Java 21 required.

This update fixes fluid GUI draw ordering, rectangular tank positioning and empty/partial tank bounds. It retains the modifier crystal fix from port.1. Actual graphical framebuffer checks cover lava, molten iron, partial/empty and stacked rectangular tanks, alongside existing core/addon rendering regressions. Production jars are assembled, inspected and checked in a normal installed server before publication.

Replace the old Tinkers21 jar with `Tinkers21-1.21.1-neoforge-3.12.1-port.2.jar`. Mantle remains `Mantle21-1.21.1-neoforge-1.11-port.0.jar`. Keep one jar per mod; do not install official Mantle alongside Mantle21. Back up worlds before updating.

This is a vibe-coded unofficial fork, not a complete official release. Switch to the official 1.21.1 release when available for safety, maintenance and compatibility. TiCEX and arbitrary optional mods/old-world migrations are not verified. The two-jar ZIP includes licenses, provenance and installation instructions; SHA256SUMS.txt identifies the exact published files.
